# Monitoreo-remoto-de-invernadero-con-STM32-y-ESP32
Sistema de monitoreo remoto de invernadero mediante LoRa. Un STM32L072 mide cada 30 segundos la temperatura y humedad del aire (DHT22) y del sustrato (YL-69), enviando los datos a una estación ESP32 LilyGO T3 con pantalla OLED. Incluye alertas por pérdida de señal, consulta local y control automático de riego y ventilación.
